# Root Academy - LMS Élite & Plateforme d'Apprentissage

Root Academy n'est pas seulement une plateforme de cours, c'est un **Learning Management System (LMS) fullstack** complet, conçu pour offrir une expérience d'apprentissage d'élite et permettre aux experts de monétiser leur savoir.

---

## Fonctionnalités Majeures

### Pour les Apprenants

- **Catalogue Dynamique** : Filtres par catégories et niveaux pour trouver la formation idéale.
- **Expérience d'Apprentissage Riche** : Lecteur supportant Vidéos, Articles (Markdown), Exercices et Quizz interactifs.
- **Suivi de Progression** : Tableau de bord personnel avec barre de progression en temps réel et historique des leçons terminées.
- **Communauté & Aide** : Chat en temps réel intégré pour échanger avec les autres étudiants et les formateurs.

### Pour les Formateurs (Studio)

- **Éditeur de Cours Intuitif** : Création de modules et leçons avec barre d'outils Markdown personnalisée.
- **Monétisation** : Intégration complète avec **Stripe** pour la vente de formations et la gestion des revenus.
- **Dashboard Instructeur** : Statistiques de ventes et gestion simplifiée du catalogue.
- **Marketing & Promotions** : Système de codes promos dynamiques avec **dates d'expiration** pour créer de l'urgence et booster les conversions.

### Core Tech & Admin

- **Authentification Sécurisée** : Système robuste via JWT avec gestion des rôles (Admin, Teacher, Student).
- **Architecture de Données** : Persistance via PostgreSQL et Prisma ORM pour une intégrité parfaite des données.

- **Validation Formateurs** : Workflow d'approbation pour garantir la qualité du contenu.

---

## Stack Technique

### Frontend

- **Framework :** React 18 (Vite)
- **Stylisation :** Tailwind CSS 4.0 (Aesthetics Premium)
- **Animations :** Framer Motion
- **Temps Réel :** Socket.io Client
- **Gestion d'État :** Zustand & Context API

### Backend

- **Runtime :** GO
- **Base de Données :** PostgreSQL
- **Sécurité :** Passport JWT & Bcrypt
- **Paiements :** Stripe API
- **Fichiers :** Cloudinary Integration
